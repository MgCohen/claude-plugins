# Review, exit and close

## Review

1. Run each item of the review checklist in `Triage · Kinds`.
2. If all items pass, tick `AI review`. Comment with a table of the checks and results.
3. If an item fails, comment with the failed items. Set Status back to Fill.
4. Tick `Owner approved` only after the owner approves in chat. Quote the approval in a comment.

Do not tick `Owner approved` on your own decision.

## Exit

Do the exit only when both check boxes are ticked.

1. Find the row of the kind in the Kinds table of `Triage · Kinds`.
2. Do its exit from the Exits table. Make the new page from the Approved template of the target database, and set its Template relation.
3. Write the page body with the section mapping table in `Triage · Kinds`.
4. Do the exit steps in `Triage · Rules`.
5. Fetch each made or changed page to verify it.
6. Reply with the links.

If an exit rule does not fit the ask, do not guess. Tell the owner and propose a rule change as an Issues row with Type Workflow and About doc set.

## Close

If the owner discards an ask, set Status to Dropped. Add a comment with the reason. If it repeats an existing item, link that item in the comment.
