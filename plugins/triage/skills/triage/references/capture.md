# Capture

Use this mode when the owner writes "idea: …", "new request" or "add to triage".

1. Find the Approved Templates row `Ask · Capture`.
2. Make a row in Asks with that row page ID as `template_id`.
3. Set Name to a short imperative title. Set Summary to one sentence from the owner's words.
4. Set Status New, Source, Priority Normal, and the Template relation to `Ask · Capture`.
5. Fetch the page until the template content is there. Then write the owner's exact words under Words.
6. Reply with the page link. Do not start the interview unless the owner asks.

If the owner gives more than one idea in one message, capture each idea as its own ask.

If `Ask · Capture` is not Approved, use its current version and tell the owner.
