# Capture

Use this mode when the owner writes "idea: …", "new request" or "add to triage".

1. Create an issue in team `MAT`, project `Triage`.
2. Write a short imperative title and one sentence from the owner's words.
3. Add the label `Intake/1 · Captured`. Set status Backlog.
4. Read the issue again to verify the project and the label.
5. Reply with the issue link. Do not start the interview unless the owner asks.

If the owner gives more than one idea in one message, capture each idea as its own issue.
